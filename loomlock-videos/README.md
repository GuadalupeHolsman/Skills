### Before publishing

- **Don Julio logo:** the logo is a public web copy recolored to gold and white. Swap in the brand's official file and get their approval.
- **Stock footage:** the clips are from Mixkit, which is free to use with no credit needed. Check that the licence allows using them next to an alcohol brand.
- **Footer:** every invitation ends with "+18 · Please drink responsibly."
- **Event details:** confirm the ones the copy takes for granted:
  - invite only
  - tap in, with phones locked at the door
  - the date shows as Thursday, 29 October 2026
- **Music:** all music is synthesized for these films.

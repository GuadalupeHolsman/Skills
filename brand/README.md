# JustBueno · Elementos de marca

Extraídos del sitio [JustBueno · Plataformas](https://guadalupeholsman.github.io/Skills/) (páginas YouTube, Spotify y Equipo) y del PDF *JustBueno post-banner* (Canva, 22 páginas).

Guía visual: [`brand/index.html`](https://guadalupeholsman.github.io/Skills/brand/)

## Contenido

| Carpeta / archivo | Qué hay |
|---|---|
| `logos/` | Símbolo, wordmark y logos horizontal y vertical en SVG vectorial, en versión crema (para fondos oscuros) y ciruela (para fondos claros). |
| `tokens.css` | Variables CSS: colores, tipografías, escalas, espaciado, radios y sombras. |
| `tokens.json` | Los mismos valores en JSON. |
| `aplicaciones/` | Las 22 piezas del PDF en JPG, como referencia. |

## Colores

| Nombre | Hex | Uso |
|---|---|---|
| Ciruela | `#3B2027` | Fondo principal, texto |
| Crema | `#F2EDE3` | Logo sobre oscuro, fondo de página |
| Naranja | `#E8651A` | Yema del símbolo, acento sobre oscuro |
| Terracota | `#C0713F` | Acento sobre claro |
| Verde | `#1B6B4A` | Rotación de episodios |
| Degradado | `#E8913F → #E08C5C → #DD8A7C` (135°) | Portadas, avatar, cabeceras |

## Tipografías

- **Display:** Cooper BT Bold / Cooper Black BT (alternativa libre: Caprasimo)
- **Acento:** Cooper BT Light Italic (alternativa: Newsreader Italic 300), una sola palabra por titular
- **Texto:** DM Sans
- **Etiquetas:** Manrope en mayúsculas, tracking .14em

Cooper BT es una fuente comercial y no se incluye aquí. El wordmark de los SVG está convertido a contornos, así que se ve bien sin la fuente instalada.

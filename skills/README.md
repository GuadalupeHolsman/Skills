# Skills para el Instagram de EatsBueno

| Skill | Para qué |
| --- | --- |
| `eatsbueno-marca` | Voz, tono, pilares y estilo visual. La cargan todas las demás. |
| `ideas-reels-instagram` | Banco mensual de ideas de reels + calendario. |
| `guion-reel` | Guion toma por toma, caption y checklist de rodaje de un reel. |
| `podcast-a-reels` | Elegir y recortar los mejores momentos de un episodio de JustBueno. |

Flujo sugerido: `ideas-reels-instagram` → `guion-reel` para las ★ → `podcast-a-reels` cada martes.

Para usarlas en Claude Code, copiá cada carpeta a `.claude/skills/` del proyecto (o `~/.claude/skills/`). En claude.ai, subí cada carpeta como skill desde Configuración → Capacidades.
